
#  Parc-Magique — Plateforme de vente de tickets

##  Présentation du projet

**Parc-Magique** est une application web développée dans le cadre de mon projet de fin d'études en Licence Informatique.

L'objectif de cette application est de proposer une plateforme permettant aux utilisateurs de **découvrir les parcs d'attractions à Oran**, consulter leurs attractions et services, et effectuer la **réservation et l'achat de tickets en ligne**.

L'application propose également un espace d'administration permettant de gérer les utilisateurs, les parcs et les tickets.

---

##  Objectifs

L'application a été conçue pour :

*  Présenter les parcs d'attractions disponibles à Oran
*  Permettre aux utilisateurs de rechercher et consulter les parcs
*  Faciliter la réservation et l'achat de tickets
*  Gérer les comptes utilisateurs
*  Consulter l'historique des tickets
*  Gérer le processus de paiement
*  Générer et consulter les informations relatives aux tickets
*  Fournir une interface d'administration
*  Gérer les parcs et leurs informations
*  Gérer les utilisateurs et les réservations

---

##  Fonctionnalités principales

###  Espace utilisateur

* Inscription
* Connexion / déconnexion
* Gestion du profil
* Consultation des parcs
* Consultation des attractions
* Réservation de tickets
* Paiement
* Consultation des tickets
* Consultation de l'historique des achats

###  Gestion des parcs

L'application permet de présenter différents parcs et espaces de loisirs à Oran, notamment :

* Manège El Hamri
* AZ Grand Oran
* Cool Park
* Kiddy Garden
* Khaled Space Kids
* Boukaa Beach
* Aquaparc Rodina
* Krichtel
  

###  Espace administrateur

L'administrateur peut notamment :

* Ajouter un parc
* Supprimer un parc
* Consulter les parcs
* Consulter les utilisateurs
* Supprimer un utilisateur
* Consulter les tickets
* Gérer les administrateurs
* Consulter certaines statistiques

##  Installation et exécution

### 1. Cloner le projet

git clone https://github.com/yasmine-art/Parc-Magique.git

### 2. Placer le projet dans XAMPP

Copier le dossier du projet dans :

C:\xampp\htdocs\

### 3. Démarrer XAMPP

Lancer :

* Apache
* MySQL

### 4. Configurer la base de données

Créer une base de données MySQL puis importer le fichier SQL du projet.

### 5. Lancer l'application

Dans le navigateur :

http://localhost/Parc-Magique/
